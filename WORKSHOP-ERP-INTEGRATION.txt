IMPORTANT ACCESS FIX
- Staff assigned only the `workshop_erp` permission can open Workshop ERP directly from Profile without being asked for the main admin emergency password.
- The main admin continues to require the emergency admin password for protected owner actions and has full Workshop ERP access. Other admins can edit/delete only within functions assigned to them.
- Server API requests validate signed Telegram identity and the active Workshop ERP role for staff; task-level writes are checked against the saved workshopAssignments.
- The main admin confirms task assignments with Done in Workshop ERP > Admin & Staff. The server updates the real ambar_admin_roles permissions and the shared workshop_erp_state record.
- Edit and Delete buttons are shown to admins assigned to the relevant Workshop ERP function. The server checks each delete against the admin’s saved function assignment; the main admin retains full access.

DEPLOY
1. Replace the matching files in the GitHub repository with this archive's files.
2. Commit and push, then wait for Render to redeploy.
3. In Admin Management, activate the staff account and select Workshop ERP.
4. As main admin, open Workshop ERP > Admin & Staff, select at least one task, and click Done.
5. Test from the staff account's Telegram Profile. The staff account should enter Workshop ERP without the emergency password prompt and should only see assigned sections.

The Admin & Staff assignment screen now groups selectable permissions by section: Workshop Floor / Work Orders, Showroom Inventory, Raw Materials, Sales Archive, Reports & Analytics, and Dashboard. Workshop areas (Cutting & Prep, Assembly, Finishing / Spray, In Stock) remain multi-select. Each section exposes separate task permissions for create/add, edit, advance stage, receive stock, cut/use material, and delete as appropriate. Edit and Delete controls are shown only when explicitly assigned, and the Flask API enforces the same granular permissions server-side. Raw Materials permissions separately control Add Material, Add/Receive Stock, Cut/Use Material, Edit Material Details, and Delete Material/Movement. No new database migration is required; assignments remain in the existing shared Workshop ERP state and admin role tables.

The Materials section also exposes Edit Material Movement and Delete controls separately according to the assigned `materials_edit` and `materials_delete` permissions. Editing a movement recalculates stock and prevents negative stock totals.

Daily Excel report delivery
---------------------------
The Daily Records by Date export downloads an Excel-compatible .xls workbook and also posts it to /api/workshop/reports/send. The backend validates the Telegram identity and Workshop ERP session, checks Reports & Analytics permission, then uses Telegram sendDocument. Leave the recipient as “My Telegram account” to send to the currently signed-in admin. Existing admin accounts can be selected from the recipient list. To send to another person, enter their numeric Telegram chat/user ID; a username by itself cannot be used by Telegram Bot API to start a private conversation. The recipient must have started the AMBAR bot.

Daily reports (Excel + PDF)
- Daily Records by Date exports category-separated worksheets/tables for sales, material movements/cut usage, production stage events, daily material stock health, restock events, and timestamped operational actions grouped by category.
- Excel-compatible .xls and PDF files can be downloaded and sent to a Telegram recipient from the export form.
- PDF generation uses the reportlab package, included in requirements.txt.
- Timestamped action capture begins after this version is deployed. Old activity strings that were stored without a timestamp cannot be reliably assigned to a historical date.


Payment Waiting workflow: Showroom Inventory separates sold units with incomplete payment into Payment Waiting. Once marked fully paid, the item automatically moves to Sold Products. All such units remain SOLD/inactive until restocked.


Daily report export update: Reports & Analytics now exports and sends PDF only. Excel export/sharing is removed. Restocked available products display a RESTOCKED tag and their details show the restock timestamp and note.
